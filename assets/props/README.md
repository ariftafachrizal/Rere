## Naming & Approval

`canonical` means the image has been explicitly approved as a visual source of truth. Drafts should use `draft-v01`, `draft-v02`, etc. and must not silently replace a canonical asset.

Recommended visual sheet content:

- front view
- 3/4 view
- side view when needed
- scale relative to Rere
- color/material swatches or notes
- close-up of signature details
- interaction/usage reference when useful

## Consistency Hierarchy

**Character Identity → Outfit → World → Prop → Scene**

For recurring props, use the exact same canonical design whenever possible. If the canonical form changes intentionally, update the Prop ID/version and document the decision.

## Binary Asset Note

The registry may define intended paths before the binary images are committed. A file is repository-hosted canonical only after the actual binary exists at the documented path.
