# Binary Asset Upload Note

The GitHub connector used for this synchronization currently supports text/UTF-8 repository file creation but does not expose a binary upload operation for local PNG/JPG files.

The canonical Rere image assets should therefore be copied into this directory from the local clone using normal Git tooling.

Recommended files from this conversation:

- `rere-character-sheet-canonical.png` — latest approved Rere character sheet / profile reference.
- `rere-character-sheet-previous.png` — previous approved character sheet retained for historical reference if desired.
- `rere-character-source-photo-reference.jpg` — source reference photo supplied by the project owner. Keep access and use policy in mind before publishing/distributing outside the private project workflow.

Do not use generated drafts as the canonical reference until explicitly approved.
