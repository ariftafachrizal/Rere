# Rere Reference Assets

This directory is reserved for canonical visual references used to keep Rere consistent across production tools.

## Current Reference Set

The canonical character references should include:

- final Rere character sheet
- alternate/final character sheet revisions when explicitly approved
- approved signature intro reference
- approved signature closing reference
- future turnaround/expression sheets

## Source of Truth

Do not treat every generated image as canonical.

Only assets explicitly marked/approved as **canonical reference** should be used as the source of truth for future character generation.

Current written rules are in:

- `docs/BRAND-GUIDELINE.md`
- `docs/CHARACTER-BIBLE-RERE.md`

When a new canonical visual is approved, update this index and preserve older references rather than silently replacing them.
