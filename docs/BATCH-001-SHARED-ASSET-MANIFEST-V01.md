## 4. Asset Creation Rule

A new shared asset follows:

**Design → Generate → Review → Canonical/Approved Derivative → Registry → Episode Use**

Never promote a scene-specific accident into a canonical asset without explicit review.

## 5. Asset Naming

Use:

`RERE-PROP-[NAME]-V01`

For episode-specific derivatives:

`RERE-EP-###-PROP-[NAME]-V01`

For scene outputs:

`RERE-EP-###-SCENE-##-[SHOT]-V##`

## 6. Reuse Rule

If the same object appears in two episodes, use the same approved asset unless a documented pedagogical reason requires a variant.

## 7. Asset Gap Priority

**P0:** character/world references required for all generation.  
**P1:** learning props required by multiple episodes.  
**P2:** episode-specific props.  
**P3:** decorative details.

Production must solve P0/P1 before P2/P3.
