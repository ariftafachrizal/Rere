# Rere — Camera & Cinematography Bible

**Status:** Production Standard — v1.0  
**Batch:** 03 — Camera / Cinematography  
**Date:** 2026-09-12  
**Scope:** image generation, video generation, storyboards, animation, thumbnails, transitions, educational scenes, and cinematic continuity.

## 1. Purpose

Camera harus menjadi bahasa visual yang membantu anak memahami cerita dan pembelajaran, bukan sekadar membuat gambar terlihat sinematik.

> **The camera follows the learning and the emotion.**

Camera consistency memastikan Rere, recurring props, dan canonical environments tetap terbaca sebagai universe yang sama ketika angle, framing, lens feel, movement, dan shot scale berubah.

## 2. Production Hierarchy

Ketika terdapat konflik:

1. Character Identity
2. Learning Intention
3. Story / Action
4. Prop Identity
5. Environment Identity
6. Camera Readability
7. Cinematic Style
8. Decorative Composition

Camera tidak boleh mengorbankan readability demi cinematic effect.

## 3. Core Camera DNA

Default Rere camera language:

- warm
- gentle
- stable
- inviting
- child-height
- clear
- playful
- emotionally readable
- moderately cinematic
- never intimidating

Visual reference: **preschool storybook brought gently to life**, bukan action movie dan bukan commercial hyper-cinematic.

## 4. Audience & Eye-Level Rule

Target utama awal: usia 2–4 tahun.

Default camera height berada dekat perspektif anak.

Gunakan eye-level atau sedikit di bawah eye-level Rere untuk membuat anak merasa ikut berada di dunia Rere.

Hindari:

- extreme high angle yang membuat Rere terlihat kecil/tidak berdaya
- extreme low angle yang membuat karakter intimidating
- distorted ultra-wide perspective
- surveillance/CCTV feeling
- adult documentary perspective tanpa alasan cerita

## 5. Shot Size System

### ECU — Extreme Close-Up

Gunakan sangat terbatas untuk:

- detail ekspresi penting
- detail learning object
- gesture kecil

Jangan gunakan untuk terlalu lama karena menghilangkan konteks.

### CU — Close-Up

Untuk:

- wajah Rere
- emosi
- pronunciation/language moment
- reaction
- prop detail

### MCU — Medium Close-Up

Default untuk dialog pendek dan explanation beat.

Rere dari dada/pinggang ke atas.

### MS — Medium Shot

Untuk interaction:

- Rere + prop
- Rere + Bunny
- Rere melakukan aktivitas

### MLS — Medium Long Shot

Untuk memperlihatkan tubuh dan sebagian environment.

### FS — Full Shot

Untuk:

- movement
- body gesture
- dance
- gross motor
- object interaction

### WS — Wide Shot

Untuk:

- establishing location
- transition
- scale
- environment discovery

### EWS — Extreme Wide Shot

Gunakan jarang untuk establishing dunia besar, nature, atau imagination world.

## 6. Default Shot Rhythm

Untuk preschool learning scenes:

**Wide → Medium → Close → Action/Prop → Reaction → Medium/Wide**

Tidak wajib memakai semua shot. Pilih hanya yang membantu pemahaman.

Default rule:

> **Context first, learning object second, emotion third.**

## 7. Composition Rules

### Primary Focal Point

Dalam satu frame harus jelas apa yang harus dilihat anak.

Priority:

1. Rere's face/action
2. primary learning prop
3. supporting character/prop
4. environment
5. decoration

### Negative Space

Sediakan ruang untuk:

- subtitles
- educational labels
- simple graphic overlays
- breathing room

Jangan menempatkan important facial features atau learning object terlalu dekat edge frame.

### Rule of Thirds

Boleh digunakan, tetapi tidak wajib.

Untuk preschool content, **clarity > compositional sophistication**.

### Symmetry

Sangat cocok untuk:

- teaching setup
- review
- counting
- color matching
- title moments

## 8. Learning Object Framing

Ketika Rere memperkenalkan satu objek:

1. tampilkan Rere melihat objek
2. pindahkan perhatian ke objek
3. beri cukup ukuran frame agar objek mudah dikenali
4. kembali ke Rere untuk response

Jangan membuat primary learning object terlalu kecil hanya demi wide cinematic shot.

> **If the child cannot easily see it, the shot failed.**

## 9. Character + Prop Framing

Recurring prop harus tetap recognizable.

Untuk signature props:

- Pink Bunny: wajah dan silhouette tidak tertutup bila identity sedang relevan.
- Backpack: cukup terlihat ketika menjadi bagian identity/transition.
- Learning Book: cover dan interaction terbaca ketika dipakai.
- Heart motif: jangan menjadi noise dekoratif.
- Crayon Kit: container dan individual crayons dapat dibedakan.

Camera angle tidak boleh menciptakan prop baru melalui distortion atau occlusion yang membingungkan.

## 10. Environment Establishing Rules

Untuk canonical location baru:

**Establish → Enter → Interact → Focus**

Contoh playroom:

1. wide establishing playroom
2. medium Rere entering
3. medium Rere + table
4. close learning object

Setelah lokasi sudah dikenal audience, establishing shot dapat dipersingkat.

## 11. Camera Movement

Default movement:

- slow push-in
- gentle pull-out
- subtle pan
- subtle tilt
- gentle tracking
- controlled orbit bila perlu

Movement harus terasa seperti kamera yang ramah dan penasaran bersama anak.

Hindari:

- rapid whip pan
- aggressive zoom
- shaky handheld
- spinning camera
- extreme orbit
- constant camera movement
- motion yang membuat anak sulit mengikuti objek

## 12. Camera Movement by Learning Beat

### Discovery

Gentle push-in / slow reveal.

### Question

Stable medium or close shot.

### Pause

**Lock camera.**

Jangan menggunakan movement yang mengalihkan perhatian ketika anak diberi waktu menjawab.

### Answer

Small push-in atau reveal ke jawaban.

### Celebration

Slightly wider framing dengan gentle movement.

## 13. Signature Interaction Camera Pattern

Gunakan:

**Rere → Question → PAUSE → Child Thinking → Answer → Reaction**

Camera during PAUSE:

- stable
- clean background
- Rere/primary object clearly visible
- no unnecessary cuts
- no distracting motion

Ini menjadi bagian dari bahasa belajar Rere.

## 14. Lens Feel

Tidak perlu mengunci focal length literal untuk setiap generation model, tetapi gunakan feel berikut:

### Normal / Natural

Default untuk mayoritas scenes.

### Mild Wide

Untuk room/environment context.

### Mild Telephoto

Untuk emotional close-up dan isolasi object.

Hindari fisheye atau exaggerated wide-angle distortion.

## 15. Depth of Field

Default: moderate, natural depth.

Background boleh sedikit soft agar Rere menonjol.

Untuk learning object:

- object harus sharp
- Rere dapat sedikit softer bila tidak sedang menjadi focal point

Jangan menggunakan extreme shallow DOF yang membuat sebagian learning object blur.

## 16. Camera + Lighting Continuity

Jika shot berada di lokasi dan waktu yang sama, pertahankan:

- camera height feel
- light direction
- shadow direction
- exposure feel
- white balance feel
- spatial orientation

Perubahan camera angle tidak boleh terasa seperti pindah ruangan.

## 17. Spatial Continuity

Untuk sequence multi-shot, pertahankan:

- screen direction
- character position
- prop relationship
- door/window orientation
- major furniture orientation
- movement direction

### 180-Degree Rule

Gunakan screen direction yang konsisten ketika Rere berinteraksi dengan karakter atau object lain.

Crossing axis hanya jika ada alasan visual yang jelas dan transition cukup aman untuk audience.

## 18. Editing & Cut Rules

Cuts harus mengikuti:

- action completion
- learning beat
- emotional beat
- natural attention shift

Hindari cutting terlalu cepat.

Untuk usia 2–4 tahun, biarkan anak mempunyai waktu untuk melihat, memproses, dan meniru.

## 19. Thumbnail / Hero Frame

Thumbnail boleh lebih expressive daripada episode shot, tetapi tetap canonical.

Priority:

1. Rere face
2. clear emotion
3. one learning/story object
4. simple environment cue
5. readable negative space for title

Jangan memasukkan terlalu banyak objects hanya untuk membuat thumbnail terlihat ramai.

## 20. Opening Camera Language

Signature opening:

> “Hai teman-teman, aku Rere, main dan belajar bersama Rere, yuk!”

Recommended visual:

- medium/full shot
- Rere faces camera
- warm environment
- friendly wave/heart gesture sesuai approved gesture system
- stable opening

Opening harus cepat dikenali sebagai Rere.

## 21. Closing Camera Language

Closing harus terasa sebagai ritual yang konsisten.

Recommended:

- medium shot
- Rere centered atau balanced
- friendly eye contact
- heart gesture
- gentle pull-out atau static end frame
- clean end-card transition

Jangan menggunakan dramatic camera movement pada closing.

## 22. Special Camera Modes

### Story Mode

Lebih banyak medium/full shots, natural movement.

### Teaching Mode

Stable framing, object clarity, centered/symmetrical compositions.

### Emotional Mode

Closer framing, slower movement, softer background.

### Action Mode

Full/medium-long, controlled tracking, clear body movement.

### Imagination Mode

Boleh lebih dynamic dan magical, tetapi tetap smooth dan readable.

## 23. Camera Rules for Muslimah Rere

Camera language tetap sama.

Perubahan wardrobe tidak boleh menghasilkan camera language berbeda.

Maintain:

- eye-level feel
- respectful framing
- child-safe composition
- same emotional proximity
- same world identity

Jangan membuat Muslimah Rere terasa seperti karakter dari franchise berbeda.

## 24. AI Generation Anchor

```text
Use the established Rere camera language.
Keep camera child-height, warm, gentle, stable, inviting, and preschool-friendly.
Prioritize learning readability and emotional clarity over cinematic complexity.
Preserve canonical character, prop, and environment relationships.
Use natural perspective with mild wide or normal lens feel.
Avoid fisheye distortion and exaggerated perspective.
Use moderate depth of field so important learning objects remain readable.
Use smooth, restrained camera movement.
During questions and pauses, stabilize the camera and reduce visual distraction.
Maintain spatial and screen-direction continuity across adjacent shots.
``` 

## 25. Negative Prompt — Camera Drift

```text
Do not use extreme wide-angle distortion.
Do not use fisheye perspective.
Do not use shaky handheld camera.
Do not use aggressive zooms or whip pans.
Do not constantly move the camera.
Do not hide the primary learning object.
Do not crop important facial features accidentally.
Do not make Rere appear intimidating through extreme low angles.
Do not make Rere appear helpless through extreme high angles.
Do not change room orientation randomly between shots.
Do not break screen direction without purpose.
Do not use extreme depth of field that blurs learning objects.
Do not prioritize cinematic spectacle over preschool readability.
``` 

## 26. Camera Preset Library

Use standardized conceptual presets:

| Preset | Purpose | Default |
|---|---|---|
| `RERE-CAM-ESTABLISH` | Location intro | WS / stable |
| `RERE-CAM-GREETING` | Opening | MS/FS / eye-level |
| `RERE-CAM-TEACH` | Teaching | MCU/MS / stable |
| `RERE-CAM-PROP` | Learning object | CU / clear |
| `RERE-CAM-REACTION` | Emotion | CU/MCU |
| `RERE-CAM-ACTION` | Movement | FS/MLS / tracking |
| `RERE-CAM-INTERACTION` | Rere + prop/character | MS |
| `RERE-CAM-PAUSE` | Child response | stable MS/MCU |
| `RERE-CAM-CELEBRATE` | Reward | MS/FS |
| `RERE-CAM-CLOSING` | Closing ritual | MS / stable |
| `RERE-CAM-IMAGINATION` | Fantasy | controlled dynamic |

## 27. Shot Naming Convention

Format:

`EP###-SC##-SH##-[CAMERA-PRESET]`

Example:

`EP001-SC04-SH02-RERE-CAM-PROP`

This allows storyboard, generation prompts, editing, and QA to reference the same camera intent.

## 28. Camera QA Checklist

### Readability

- [ ] Primary focal point immediately clear.
- [ ] Rere readable.
- [ ] Learning prop readable.
- [ ] No important detail accidentally cropped.

### Continuity

- [ ] Camera height consistent.
- [ ] Screen direction consistent.
- [ ] Environment orientation consistent.
- [ ] Prop relationship consistent.
- [ ] Lighting direction consistent.

### Preschool Safety / Comfort

- [ ] No dizzying movement.
- [ ] No aggressive zoom.
- [ ] No frightening perspective.
- [ ] Enough processing time.

### Learning

- [ ] Camera supports learning intention.
- [ ] Pause is visually stable.
- [ ] Answer/reward has clear visual emphasis.

### Brand

- [ ] Feels like Rere.
- [ ] Warm and playful.
- [ ] Cinematic but not intimidating.

## 29. Production Principle

> **Camera is not decoration. Camera is attention guidance.**

> **Show the child where to look, give them time to think, then show what happens next.**
