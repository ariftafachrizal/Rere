# RERE BATCH 001 — EDITING TEMPLATE V01

**Status:** Production Standard  
**Episodes:** EP001–EP006  
**Date:** 2026-09-12

## 1. Timeline Architecture

Standard order:

`OPENING → HOOK → CTA(optional) → LEARNING BLOCKS → PARTICIPATION → CREATE/APPLY → REVIEW → ACHIEVEMENT → CLOSING`

## 2. Reusable Timeline Tracks

Suggested track groups:

- V1: primary scene
- V2: secondary/insert scene
- V3: learning-object close-up
- V4: editorial overlays
- V5: subtitles
- A1: Rere voice
- A2: child-response/PAUSE room
- A3: SFX
- A4: music
- A5: ambience

## 3. Scene Block Template

Every learning block contains:

1. setup
2. discovery
3. question
4. PAUSE
5. answer
6. imitation/action
7. reward
8. transition

## 4. Pacing

The target is calm engagement, not maximum cut frequency.

Use longer holds when:

- asking a question
- showing a learning object
- waiting for child action
- emphasizing vocabulary

Use shorter cuts when:

- entering a new activity
- changing location
- revealing a completed action

## 5. Transitions

Preferred:

- clean cut
- gentle dissolve where motivated
- simple visual match
- natural movement transition

Avoid:

- excessive wipes
- spins
- flashes
- shake transitions
- meme-style effects

## 6. Text / Subtitle System

Text should support comprehension, not become a second lesson channel.

For learning words:

- one target word at a time
- large readable typography
- strong contrast
- safe margins
- no unnecessary animation

Never depend on AI-generated text inside scene renders.

## 7. PAUSE Editing

During PAUSE:

- hold visual composition
- reduce camera movement
- reduce music density
- keep target object visible
- leave response space

Do not cut away because the timeline feels slow.

## 8. Reward Timing

Reward follows the response window, not before it.

Preferred sequence:

`QUESTION → PAUSE → RESPONSE → RERE CONFIRMATION → SOFT REWARD`

## 9. Motion Intensity

Maintain project scale 0–4.

Most learning content should stay at **0–2**.

## 10. Episode Template

```text
00:00 Opening
00:12 Hook
00:24 CTA / optional
00:30 Learning Block 1
00:50 Learning Block 2
01:10 Learning Block 3
01:30 Learning Block 4
01:50 Learning Block 5
02:10 Participation / Quiz
02:40 Create / Apply
03:10 Review
03:20 Achievement
03:30 Closing
```

Times are a planning scaffold, not a mandatory edit. Voice timing and child-centered testing have priority.

## 11. Export Versions

- `ROUGH-V01`
- `REVIEW-V01`
- `QA-V01`
- `FINAL-V01`

## 12. Editing QA

- no accidental jump cuts
- dialogue sync correct
- target object visible when named
- PAUSE preserved
- subtitles synchronized
- music ducking correct
- SFX timed after response
- no distracting overlays
- canonical opening/closing intact

## 13. Golden Rule

> **Edit for the child's attention and participation, not for the editor's fear of empty time.**
