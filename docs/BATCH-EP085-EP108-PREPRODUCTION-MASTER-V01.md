## QA / safety locks
No pressure to read fluently; early literacy is recognition/listening/speaking. No copyrighted brand characters or logos in learning cards. Drawing tools are age-appropriate; large pieces only for collage. Story sequences have one intended order. For guessing/problem solving, clues must support exactly one plausible answer. Text on-screen is optional support, never the only learning channel.
