# RERE BATCH 001 — PACKAGING SYSTEM V01

**Status:** Production Standard  
**Episodes:** EP001–EP006  
**Date:** 2026-09-12

## 1. Principle

> Make the promise clear, honest, recognizable, and useful to parents.

Packaging should attract without misleading or overstimulating children.

## 2. Title Formula

Primary structure:

`Rere + Learning Topic + Child-Friendly Benefit/Activity`

Examples:

- Rere Belajar Warna | Petualangan Warna untuk Anak
- Rere Belajar Bentuk | Yuk Cari Bentuk Bersama!
- Rere Belajar Angka 1–5 | Yuk Hitung Bersama Rere!

## 3. Thumbnail System

Required:

- canonical Rere
- one dominant learning idea
- clear object/objects
- simple composition
- readable at small size
- signature pink accent
- honest representation of episode

Avoid:

- excessive text
- clickbait expressions
- fake danger
- unrelated objects
- crowded compositions
- AI-generated typography when editorial typography is available

## 4. Thumbnail Variants

Create up to three controlled variants:

A — Rere + primary object  
B — Rere + learning action  
C — Rere + outcome/reward

Only test one major variable at a time.

## 5. Description Template

```text
Hai teman-teman! 🌸

Hari ini kita belajar [TOPIK] bersama Rere.

Di video ini, anak diajak untuk [LEARNING OBJECTIVE].

Cocok untuk anak usia 2–4 tahun.

Belajar • Bermain • Berbagi
Bersama Rere!
```

Do not make unsupported developmental or academic claims.

## 6. Playlist Architecture

Initial playlists:

- Belajar Warna Bersama Rere
- Belajar Bentuk Bersama Rere
- Belajar Angka Bersama Rere
- Belajar & Bermain Bersama Rere
- Kebiasaan Baik Bersama Rere

## 7. Cross-Episode Packaging

EP001–EP006 should visually belong to one recognizable collection while retaining a distinct learning topic.

Use consistent:

- Rere treatment
- typography
- logo placement
- accent language
- thumbnail framing logic

## 8. Parent Trust

Packaging must make it easy for caregivers to identify:

- topic
- approximate age suitability
- learning activity
- Rere brand identity

Never imply guaranteed developmental outcomes.

## 9. Shorts / Vertical Derivatives

A long-form episode may produce short derivatives, but the short must retain:

- canonical Rere
- clear context
- one learning moment
- no misleading crop
- no altered identity

## 10. Packaging QA

- [ ] title matches actual content
- [ ] thumbnail matches actual content
- [ ] age language appropriate
- [ ] no misleading claim
- [ ] no fear bait
- [ ] canonical Rere
- [ ] target object visible
- [ ] text readable
- [ ] mobile-safe composition

## 11. Golden Rule

> **The thumbnail makes a promise; the episode must keep it.**
