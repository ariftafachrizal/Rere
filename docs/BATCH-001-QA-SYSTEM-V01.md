# RERE BATCH 001 — QA SYSTEM V01

**Status:** Production Standard  
**Batch:** `BATCH-001`  
**Episodes:** EP001–EP006  
**Target:** Ages 2–4  
**Date:** 2026-09-12

## 1. Purpose

Provide a repeatable approval system for a multi-episode batch without lowering character, educational, safety, or production standards.

## 2. QA Philosophy

> **A cheaper generation is never a reason to accept identity drift or educational ambiguity.**

QA is performed at asset, shot, scene, episode, and batch levels.

## 3. Severity

- **P0 — Critical:** unsafe content, wrong character identity, unusable anatomy, misleading educational content. Immediate reject.
- **P1 — Major:** canonical prop/world drift, wrong learning target, broken continuity, voice inconsistency. Reject before next gate.
- **P2 — Minor:** small framing, timing, SFX, subtitle, or polish issue. Fix during revision.
- **P3 — Cosmetic:** non-blocking polish. May be queued after core approval.

## 4. Asset QA

### Character
- face, eyes, eyelashes, nose, lips
- hair and ponytail/hijab
- anatomy/proportion
- canonical outfit
- skin tone
- age perception

### Props
- silhouette
- color identity
- major markings
- material
- scale
- interaction points

### World
- architecture
- major furniture
- anchor props
- palette relationships
- child scale

## 5. Shot QA

For every shot:

- intended framing is achieved
- focal point is obvious within 1–2 seconds
- Rere's eye direction supports attention
- action reads without explanation
- no malformed hands/objects
- no accidental duplicates
- no text artifacts
- lighting is stable
- target learning object is clear

## 6. Learning QA

Check:

1. What should the child notice?
2. What should the child say/do?
3. Is that action explicit?
4. Is PAUSE long enough?
5. Is the answer/reward clear?
6. Is vocabulary repeated meaningfully?
7. Does the episode remain within its learning promise?

## 7. Child-Centered QA

Review as a 2–4-year-old experience:

- visual hierarchy is simple
- object scale is readable
- speech is understandable
- pacing is calm enough to process
- repetition supports learning
- participation is possible without adult explanation
- no unnecessary fear, conflict, or overstimulation

## 8. Parent-Trust QA

- educational purpose is obvious
- title/thumbnail is honest
- no manipulative fear bait
- no inappropriate dialogue
- no unsafe imitation
- no unexplained commercial pressure

## 9. Cross-Episode QA

Compare EP001–EP006 for:

- Rere identity
- outfit logic
- voice identity
- recurring prop design
- world continuity
- camera language
- lighting language
- music/SFX identity
- opening/closing consistency
- typography and packaging

## 10. Scorecard

Each episode receives 0–2 per category:

| Category | 0 | 1 | 2 |
|---|---|---|---|
| Character consistency | fail | acceptable | exact |
| Prop consistency | fail | acceptable | exact |
| World continuity | fail | acceptable | exact |
| Learning clarity | unclear | mostly clear | immediate |
| Participation | absent | weak | strong |
| Voice | inconsistent | minor issue | canonical |
| Audio | distracting | acceptable | clear |
| Editing | confusing | acceptable | purposeful |
| Child suitability | poor | acceptable | strong |
| Parent trust | concern | acceptable | strong |

**18–20:** approve  
**15–17:** revise  
**<15:** reject/rework

Any P0/P1 issue overrides the numeric score.

## 11. Approval Gates

`ASSET QA → SCENE QA → EPISODE QA → BATCH QA → PACKAGING QA → PUBLISH QA`

No episode is marked ready to publish solely because the scene renders successfully.

## 12. Defect Log

Every rejected item records:

- episode
- shot
- asset/version
- defect
- severity
- likely source
- corrective action
- replacement version
- reviewer
- date

## 13. Golden Rule

> **If the child is confused, simplify. If Rere is inconsistent, regenerate. If a canonical asset drifts, reject.**
