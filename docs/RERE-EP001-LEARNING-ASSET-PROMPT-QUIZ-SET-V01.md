## Prompt

Create one clean, reusable **EP001 mini color quiz asset set** for the Rere universe.

The set must contain exactly three approved learning-object representatives:
1. one red apple for **RED / MERAH**
2. one yellow banana for **YELLOW / KUNING**
3. one pink flower for **PINK / MERAH MUDA**

Use the attached approved EP001 learning assets as direct visual continuity references. Preserve their recognizable object identity, proportions, material language, and teaching-color clarity.

IMPORTANT:
This is a **reference set**, not a quiz scene.

The three objects may be presented together in one clean asset sheet for production reference, but each object must remain visually distinct and individually reusable later.

OBJECT RULES:
- exactly one red apple
- exactly one yellow banana
- exactly one pink flower
- no duplicate objects
- no additional fruit
- no additional flowers
- no extra banana
- no competing teaching objects
- no face
- no eyes
- no mouth
- no anthropomorphic expression
- no character
- no text
- no letters
- no numbers
- no quiz question
- no answer markers
- no checkmarks
- no X marks
- no arrows
- no highlighting
- no pointing hand
- no labels
- no logo
- no watermark

COLOR RULES:
- apple must read immediately as red
- banana must read immediately as yellow
- flower petals must read immediately as pink
- do not introduce alternate colors that could become plausible teaching answers
- natural secondary colors are allowed only where already inherent to the approved objects, such as apple stem/leaf and flower stem/leaves
- keep each target color visually dominant within its own object
- no color gradients or dramatic lighting that make the target color ambiguous

PRESENTATION:
- clean isolated preschool asset-sheet presentation
- generous spacing between the three objects
- each object fully visible
- simple neutral background
- consistent scale and visual treatment
- no environment
- no playroom
- no character
- no hands
- no table clutter
- no decorative props
- no visual hierarchy suggesting one object is the answer
- no object highlighted or emphasized over another

QUIZ SAFETY / ANSWER LEAKAGE:
The final quiz scene must later be able to present one question at a time with one plausible answer.

Therefore this asset set must contain **no answer leakage**:
- no checkmark
- no glow
- no outline
- no spotlight
- no pointer
- no visual cue
- no text naming colors
- no arrangement that communicates a correct answer

STYLE:
Soft pastel 3D CGI/kawaii preschool visual language consistent with the attached Rere references and approved learning assets. Friendly, calm, premium children's educational aesthetic. The three objects should feel like members of the same Rere learning universe.

## Acceptance criteria

- each target color is immediately clear
- the three objects are visually consistent with their approved individual learning assets
- no duplicate or extra object
- no answer leakage
- no text or labels
- no anthropomorphic features
- no distracting background
- all objects fully visible
- suitable for later one-question-at-a-time S09 production
