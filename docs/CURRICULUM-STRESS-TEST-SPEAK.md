# Rere Curriculum Stress Test — SPEAK

**Status:** Completed — 2026-09-12

## Purpose

Stress test ini menguji apakah SPEAK sebagai Core Pillar cukup jelas, luas, dan tahan terhadap berbagai pengalaman belajar anak usia 2–4 tahun tanpa berubah menjadi:

- kursus English;
- daftar vocabulary;
- grammar curriculum;
- quiz/worksheet curriculum;
- atau pillar yang mengambil wilayah DISCOVER, FEEL, LIVE, dan CREATE.

Stress test menggunakan prinsip final Rere:

> **Activity does not determine the pillar. Learning intention determines the pillar.**

# B. Boundary Stress Test

## 26. Counting apples

- If the intention is **understanding/use of number concepts** → DISCOVER.
- If the intention is **using number words to communicate during play** → SPEAK can be primary.

**Result: PASS.** Primary intention rule prevents ambiguity.

## 27. Naming colors

- Naming “red/blue” to communicate → SPEAK.
- Sorting colors → DISCOVER.

**Result: PASS.** Vocabulary is not automatically SPEAK; the communicative function determines the pillar.

## 28. Reading a story

- Understanding/retelling language → SPEAK.
- Inventing a new ending → CREATE.

**Result: PASS.** Story boundary is explicit.

## 29. Singing

- Singing to practice sound/language/phrases → SPEAK.
- Creating rhythm/song/movement as expression → CREATE.

**Result: PASS.** Music overlap is manageable through intention.

## 30. “I’m angry”

- Learning language to name/communicate an emotion → SPEAK.
- Understanding and regulating anger → FEEL.

**Result: PASS.** Language is a tool; emotional learning remains FEEL.

## 31. “Please stop” / “No”

- Learning to communicate a boundary → SPEAK.
- Understanding safety/appropriate boundaries → LIVE or FEEL depending on intention.

**Result: PASS.** SPEAK can support agency without owning the underlying safety/values curriculum.

## 32. “Can you help me?”

- Learning to ask for help → SPEAK.
- Building independence/help-seeking as a life skill → LIVE/FEEL depending on context.

**Result: PASS.** Functional communication remains a legitimate SPEAK outcome.

## 33. Pretend doctor

- Using phrases such as “Where does it hurt?” / “Open your mouth” → SPEAK.
- Pretend role-play itself → CREATE.

**Result: PASS.** Communication can be embedded inside creative play.

## 34. Puzzle together

- Using language to request, describe, and collaborate → SPEAK.
- Solving the puzzle → DISCOVER.

**Result: PASS.** The same activity can legitimately belong to different pillars.

## 35. Sharing a toy

- Language for requesting/negotiating turns → SPEAK.
- Understanding empathy/conflict → FEEL.
- Learning routine/behavioral responsibility → LIVE.

**Result: PASS.** Three-pillar overlap is intentional, not a structural problem.

## 36. Washing hands

- Understanding “wash/rinse/dry” language → SPEAK.
- Understanding hygiene routine → LIVE.

**Result: PASS.** Language remains a communication lens, not a replacement for life-skills learning.

## 37. Drawing a house

- Describing the picture → SPEAK.
- Creating the picture → CREATE.

**Result: PASS.** Expression and communication are separated by intention.

## 38. Animal facts

- Understanding facts about animals → DISCOVER.
- Using animal vocabulary in conversation → SPEAK.

**Result: PASS.** Prevents SPEAK from becoming a fact-learning pillar.

## 39. Letter recognition

- Understanding letter/symbol as a concept → DISCOVER / cross-domain literacy foundation.
- Playing with letter sounds in oral language → SPEAK.
- Designing letters creatively → CREATE.

**Result: PASS.** Early literacy remains cross-domain.

## 40. Following a safety instruction

- Understanding “stop / wait / stay here” → SPEAK as communication learning.
- Understanding why the rule exists → LIVE.

**Result: PASS.** Language and values/safety can coexist without collapsing into one pillar.

# C. Stress-Test Findings

## Finding 1 — SPEAK is broader than English

The framework survives Indonesian-only, English-only, mixed-language, nonverbal, and multilingual communication examples. This confirms that the pillar's identity is **communication**, not English instruction.

## Finding 2 — English has a clear strategic role without becoming the pillar identity

English remains a major production requirement for Rere, but the learning logic stays communication-first.

This is important because otherwise Rere could accidentally become a vocabulary/English channel rather than a broader early-childhood learning companion.

## Finding 3 — Comprehension must remain a first-class outcome

The stress test repeatedly produced valid experiences where the child learns by listening, pointing, acting, choosing, or showing understanding without producing English.

Therefore:

> **Understanding is learning. Speaking is not the only evidence of communication growth.**

## Finding 4 — Imitation should remain a method, not the developmental endpoint

“Repeat after me” is useful occasionally, especially for playful language and sound awareness, but cannot define SPEAK's progression.

The approved progression therefore moves toward meaningful use and interaction.

## Finding 5 — Vocabulary quantity is a weak quality metric

A large vocabulary list can look educational while producing little meaningful communication.

Rere should prioritize:

**usefulness → context → reuse → transfer**

rather than vocabulary count alone.

## Finding 6 — Multilingual response is structurally supported

The framework accepts Indonesian, English, mixed language, gesture, and action as legitimate responses. This avoids creating unnecessary performance pressure while still giving English a consistent role.

## Finding 7 — Cross-pillar overlap is healthy

No structural conflict was found in the tested boundary cases. The primary learning intention rule consistently resolves overlap.

## Finding 8 — One new implementation rule is reinforced

Every SPEAK episode should explicitly identify the **communication function**, not only vocabulary.

Example:

Weak brief:
> Teach “apple, banana, orange.”

Stronger brief:
> Child practices naming and choosing fruit during pretend snack play.

The second creates a communicative reason for the language to exist.

# D. Final Stress-Test Verdict

### Result: PASS — No structural revision required

SPEAK passes the stress test as a Core Pillar.

The framework is sufficiently broad to support:

- listening;
- comprehension;
- vocabulary;
- functional phrases;
- conversation;
- social communication;
- narrative language;
- playful sound awareness;
- multilingual communication;
- English exposure;
- transfer/generalization.

At the same time, its boundaries remain clear enough to avoid absorbing:

- cognitive exploration → DISCOVER;
- emotional understanding/regulation → FEEL;
- values, routines, independence, safety → LIVE;
- creative expression and story creation → CREATE.

### Approved operating principle

> **SPEAK is about using communication to connect with the world. English is an important language pathway inside SPEAK, not the definition of SPEAK.**

### Production implication

Future SPEAK episode briefs should contain at minimum:

1. Primary communication intention
2. Communication function
3. Core language
4. Context
5. Child response opportunity
6. Pause/processing moment
7. Variation/reuse opportunity
8. Supporting pillars/capabilities
9. English exposure role, when applicable

---

**Conclusion:** SPEAK is ready to move from framework development into the next curriculum layer: **Three-Year Developmental Roadmap → Annual Journey → Chapter/Quarter structure → Theme Clusters → Learning Experiences.**
