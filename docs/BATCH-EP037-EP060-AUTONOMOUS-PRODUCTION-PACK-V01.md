### Safety/QA
Emotions are validated, never shamed. Fear scenes are mild and immediately resolve. EP054–058 use supervised, clearly pretend or controlled safety contexts; never depict dangerous traffic as a game. EP059 avoids startling audio. EP060 uses toy movement, not unsafe physical running. For EP056 avoid frightening emergency scenes and medical procedures. Every question has one plausible answer.

### Gemini contract
Attach canonical references in hierarchy: Rere → face/expression when relevant → outfit → world → recurring prop → learning object → shot specification. Prompt modules: SYSTEM → CHARACTER → WORLD → PROP → OBJECTIVE → ACTION → CAMERA → LIGHT → MOTION → SCENE → NEGATIVE → QA.
