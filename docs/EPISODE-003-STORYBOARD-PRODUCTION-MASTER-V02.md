## 0. PURPOSE

Blueprint visual untuk mengajarkan counting 1–5 melalui benda konkret. Karakter, dunia, dan prop yang sudah approved **tidak dibuat ulang**; Gemini hanya merender scene berdasarkan canonical references.

**Learning promise:** anak belajar mengucapkan urutan 1–5 sambil melihat **one-to-one correspondence**: satu kata angka untuk satu benda.

**Learning flow:** SEE → TOUCH/MOVE ONE OBJECT → COUNT → PAUSE → REVEAL → COUNT TOGETHER → REPEAT.

---

# 1. NON-NEGOTIABLE COUNTING INVARIANTS

1. Gunakan satu keluarga benda yang identik, sederhana dan mudah dihitung.
2. Jumlah aktual harus selalu sama dengan jumlah yang disebut.
3. Setiap benda menerima tepat satu counting word.
4. Tidak boleh ada benda tersembunyi, duplicate, atau benda yang keluar-masuk frame tanpa alasan.
5. Posisi benda yang sudah dihitung harus tetap terlihat.
6. Saat total ditanyakan, semua benda 1–5 harus terlihat jelas.
7. Number card boleh menjadi pendukung, bukan pengganti benda konkret.
8. Tidak ada konsep baru selain count 1–5.

---

# 2. GLOBAL VISUAL LANGUAGE

- Canonical Rere + canonical playroom.
- Child-height camera.
- Learning surface stable and uncluttered.
- One object family only in the main counting area.
- Motion level 1–2.
- Music ducks during counting and pauses.
- Hands must visibly touch/move the counted object.

---

# 3. CONTINUITY MAP

Rere works at the same child-scale table. Five identical approved countable toys start in a visible supply area. As each toy is counted, Rere moves it into one clean row from left to right. Once placed, it stays there. By S06 there are exactly five toys in the completed row.

Recommended object identity: use one approved stable toy family from the numeracy asset set. Do not switch object design between shots.

## S02 — COUNTING MISSION
**Time:** 0:12–0:28  
**Camera:** WS → MS  
**Motion:** 2

**Purpose:** show a small collection and motivate counting.

**Action chain:** Rere reaches learning table → sees a group of five identical toys → briefly looks from toys to camera → gathers attention.

**Dialogue:** “Wah, ada mainan! Yuk kita hitung bersama Rere.”

**Critical rule:** all five toys are visible and countable, but Rere does not count them yet.

**Gemini:** canonical playroom, five identical approved countable toys, clean separation, no other toy family in focal area.

**Reject:** fewer/more than five, partial occlusion, mixed toy types, duplicates.

---

## S03 — ONE AND TWO
**Time:** 0:28–0:50  
**Camera:** MS → CU on hands/row  
**Motion:** 1–2

**Learning objective:** establish one-to-one counting.

**Action chain:** Rere takes first toy → places it in row → says “satu” → takes second toy → places beside first → says “dua”.

**Dialogue:** “Kita mulai. Satu... dua.”

**Visual counting invariant:** exactly two toys in the counted row at the end; remaining three toys remain visibly separated in supply area.

**Audio:** one soft placement SFX per toy; no overlapping speech.

**Gemini:** physically believable hand-to-object movement. Preserve each placed toy. Make the two counted objects clearly separable.

**Reject:** one word assigned to two objects, toy disappears, object overlap makes count ambiguous.

---

## S04 — THREE
**Time:** 0:50–1:12  
**Camera:** CU learning surface → gentle pull to include Rere  
**Motion:** 1

**Learning objective:** count three objects sequentially.

**Action:** Rere points/touches each object in order, adding the third to the row.

**Dialogue:** “Sekarang jadi berapa? Kita hitung: satu... dua... tiga.”

**PAUSE:** 3 sec after the row is stable.

> “Tiga!”

**Invariant:** exactly three visible objects in row, no object touching/covering another.

**Gemini:** show three identical approved objects in a straight, readable row. Rere's finger/hand clearly indicates one object at a time. No extra circular/number-like distractors in focus.

**Reject:** four objects, hidden object, ambiguous touch order, duplicate overlap.

---

## S05 — FOUR
**Time:** 1:12–1:34  
**Camera:** CU → MS  
**Motion:** 1

**Action:** add fourth toy to the right end. Rere counts all four once from left to right.

**Dialogue:** “Tambah satu lagi. Yuk hitung: satu, dua, tiga, empat.”

**PAUSE:** 3 sec.

> “Empat!”

**Visual:** exactly four in row; fifth remains visibly in supply position if composition allows.

**Gemini:** preserve previous three objects exactly and add only one identical fourth object. Rere's hand moves fourth object into place, then points/counts each once. Stable geometry.

**Reject:** row changes order unexpectedly, existing objects duplicate, total not four.

---

## S06 — FIVE
**Time:** 1:34–1:58  
**Camera:** CU row → MS with Rere  
**Motion:** 1–2

**Learning objective:** complete sequence 1–5.

**Action:** Rere adds fifth object → counts all five from left to right.

**Dialogue:** “Satu lagi! Sekarang ada berapa? Satu... dua... tiga... empat... lima!”

**PAUSE:** 4 sec.

> “Lima!”

**Critical invariant:** exactly five objects, all fully visible, stable and separately countable.

**Gemini:** show exactly five identical approved toys in one row. Rere physically places the fifth, then sequentially indicates all five. No object leaves the row. Camera must not crop the row.

**Reject:** any count mismatch; object cropped/hidden; camera angle creates overlap; extra toy appears.

---

## S07 — CHILD PARTICIPATION
**Time:** 1:58–2:40  
**Camera:** stable MS, child-facing  
**Motion:** 0–1

**Purpose:** give the child a real turn.

**Action:** Rere sits/stands beside the completed five-object row, looks into camera, gestures gently toward the objects.

**Dialogue:** “Sekarang giliran teman-teman. Ada berapa mainan?”

**PAUSE:** 5 sec.

Then:
> “Yuk kita hitung bersama. Satu, dua, tiga, empat, lima!”

**Composition:** all five objects remain visible during the full pause.

**Audio:** near-silence during pause; soft reward chime after joint count.

**Gemini:** keep five objects fixed and unobstructed. Rere invites rather than answers immediately. Neutral supportive expression during pause.

**Reject:** Rere points to or labels number five before pause; objects move/disappear; camera cuts away.

---

## S08 — REVIEW 1–5
**Time:** 2:40–3:10  
**Camera:** MCU → learning CU  
**Motion:** 1

**Purpose:** retrieval and sequence reinforcement.

**Action:** Rere traces the five-object row left-to-right while saying 1–5. Optional number cards 1–5 appear as an editorial/approved visual support only if already canonical.

**Dialogue:** “Satu, dua, tiga, empat, lima. Lima mainan!”

**Learning rule:** no new quantity, no backward counting, no addition/subtraction.

**Gemini:** stable five-object row and canonical Rere. If number cards are used, use approved references and keep them secondary.

**Reject:** number cards imply a different quantity, object count changes, new math concept appears.

# 5. EDITING / AUDIO RULES

- Count words must align exactly with visible object touches.
- Do not montage away the correspondence between word and object.
- Pause is sacred; no fast B-roll over it.
- SFX must reinforce placement, not distract from speech.
- Keep completed row visible across transitions.
- If a generated clip has count ambiguity, replace it rather than hiding the error in editing.

# 6. GEMINI PACKAGE

Attach: canonical Rere → canonical face if needed → outfit → canonical playroom → approved numeracy/countable-object reference → shot specification.

**Universal negative:** no character redesign, face drift, hairstyle/outfit drift, adult proportions, extra fingers/limbs/eyes, malformed hands, floating objects, duplicate objects, missing objects, hidden counted objects, photorealism, scary mood, random props, geometry drift, text artifacts, watermark/logo, clutter, excessive camera motion.

# 7. QA GATE

- [ ] Actual count equals spoken count.
- [ ] Exactly one object receives each count word.
- [ ] Five-object final state is exact.
- [ ] No object disappears between frames.
- [ ] Child can visually count without obstruction.
- [ ] Pause is preserved.
- [ ] Canonical Rere/world/object identity is stable.

**Golden rule:** counting accuracy outranks visual novelty.
