# RERE BATCH 001 — VOICE & AUDIO PLAN V01

**Status:** Production Standard  
**Episodes:** EP001–EP006  
**Date:** 2026-09-12

## 1. Objective

Produce six episodes efficiently while keeping one unmistakable Rere voice and one coherent sonic universe.

## 2. Voice Session Strategy

Batch recording/generation should group:

1. canonical opening
2. episode dialogue
3. PAUSE markers
4. reactions
5. praise/reward lines
6. canonical closing

Canonical opening and closing should be treated as reusable master assets where possible.

## 3. Voice Lock

All episodes must use the Voice Bible identity:

- warm
- cheerful
- curious
- patient
- clear
- preschool-friendly
- Indonesian primary

Avoid shouting, rushed delivery, excessive baby talk, sarcasm, or teacher-like lecturing.

## 4. Dialogue Versioning

`RERE-EP-XXX-VOICE-V01`

Each line should retain:

- exact text
- emotion
- estimated duration
- pronunciation notes
- pause duration
- scene/shot ID

## 5. PAUSE Recording

Do not fill child response windows with Rere chatter.

The timeline must preserve explicit response space. Music density should drop during PAUSE.

## 6. Audio Layer Hierarchy

1. Rere dialogue
2. child participation space
3. learning/reward SFX
4. music
5. ambience

Dialogue always wins.

## 7. Batch Music Strategy

Create reusable stems:

- opening
- discovery
- learning
- thinking/PAUSE
- create activity
- achievement
- closing
- neutral ambience

Music should be recognizable as Rere without becoming repetitive or overstimulating.

## 8. SFX Library

Reusable low-intensity sounds:

- soft sparkle
- gentle correct cue
- page turn
- crayon movement
- soft object pickup
- ball roll
- tiny footsteps
- room ambience

Avoid alarm-like, startling, aggressive, or excessively loud effects.

## 9. Batch Mixing

Use a common mix template across EP001–EP006. Normalize workflow settings at the project level, then perform episode-specific human QA.

## 10. Voice QA

- identity matches master
- pronunciation clear
- target vocabulary emphasized naturally
- no clipping/noise
- pauses preserved
- emotion appropriate
- no sudden loudness jumps

## 11. Audio QA

- dialogue intelligible on phone speaker
- music does not mask words
- SFX never competes with target vocabulary
- PAUSE is acoustically clear
- transitions are not startling
- opening/closing sonic identity is consistent

## 12. Batch Deliverables

For each episode:

- dialogue master
- clean dialogue stems
- music stem references
- SFX cue sheet
- ambience stem
- mixed review audio
- final audio version

## 13. Golden Rule

> **The child should hear what matters before hearing what is decorative.**
