## 3. Quiz Set

`RERE-LP-QUIZ-SET-01` consists of three-object layouts derived from the locked learning props.

Required variants:

- **Quiz A:** red target among two non-red distractors.
- **Quiz B:** yellow target among two non-yellow distractors.
- **Quiz C:** pink target among two non-pink distractors.

Distractors must be visually distinct without introducing unnecessary new object designs. Prefer reuse of the five locked learning props.

## 4. Visual Rules

- Preschool scale.
- Rounded silhouettes.
- Soft 3D CGI/kawaii rendering.
- Tactile toy-like materials.
- Simple shapes that read immediately on a mobile screen.
- Target colors must be visually unambiguous.
- Avoid gradients that make a target object appear to be multiple colors.
- Avoid tiny details that compete with the color-learning objective.
- Keep object lighting soft and consistent with the Rere universe.
- Do not redesign these objects between shots.

## 5. Color Readability Rules

### Red Apple
Red body must dominate; green leaf is secondary and must not obscure the red learning cue.

### Yellow Banana
Yellow body must dominate; brown ends are acceptable as natural secondary details.

### Blue Ball
Blue body must dominate; white star accents are secondary and must not change the object's classification.

### Green Plant
Green leaves must dominate; pot remains neutral/light so the green target is clear.

### Pink Flower
Pink petals must dominate; yellow center and green leaves remain secondary.

## 6. Scene Derivative Rules

When using these props in scene generation:

1. Use the supplied master-sheet visual as reference.
2. Preserve silhouette, material, proportions, and target color.
3. Scale the object to the scene without changing its design.
4. Keep camera angle consistent with the storyboard.
5. Do not add decorative features not present in the locked design.
6. Do not create a new canonical version from a successful scene render.
