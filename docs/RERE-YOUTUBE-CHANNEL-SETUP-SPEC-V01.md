# RERE — YOUTUBE CHANNEL SETUP SPEC V01

**Status:** ACTIVE / CANONICAL  
**Date:** 2026-09-14  
**Purpose:** Practical setup specification for the actual Rere YouTube channel.

## 1. Channel identity

### Working channel name
**Rere**

Final public channel name and handle must be locked during channel creation after availability is checked.

### Brand promise
Rere is a friendly learning companion for young children: play, discover, speak, feel, live and create through safe, meaningful, playful videos.

### Primary audience
- Child viewer: ages 2–4 during the first six months.
- Decision maker: parents/caregivers.

## 2. Channel profile package

Prepare before or during channel setup:

- profile picture: canonical Rere identity / approved avatar crop
- banner: Rere channel identity using canonical brand system
- channel name
- handle
- channel description
- relevant links/contact information if needed
- channel keywords

Do not invent a new Rere design for the profile package.

## 4. Channel settings checklist

Configure in YouTube Studio:

- country/region
- channel keywords
- audience setting
- channel visibility
- other relevant advanced settings

For a channel whose primary content is intentionally created for young children, the audience classification must be handled deliberately and accurately. YouTube provides channel-level and video-level audience settings; individual video settings can override the channel setting. See the official YouTube Help references below.

## 5. Home layout

Initial homepage should prioritize clarity rather than excessive sections.

Recommended order:

1. channel introduction / strongest entry content
2. latest long-form episodes
3. Belajar Konsep Dasar
4. Bahasa & Bicara
5. Perasaan & Berteman
6. Kebiasaan Baik
7. Kreasi & Imajinasi
8. Rere Shorts

Revisit after enough published content exists to justify a different layout.

## 6. Playlist naming convention

Use stable, parent-friendly Indonesian names:

- Mulai Belajar Bersama Rere
- Belajar Konsep Dasar
- Bahasa & Bicara
- Perasaan & Berteman
- Kebiasaan Baik
- Kreasi & Imajinasi
- Rere Shorts

Avoid making dozens of playlists at launch.

## 7. Upload defaults

Prepare a reusable metadata template containing:

### Title
`Rere [Learning Topic] — [Activity/Adventure] | Belajar Bersama Rere`

### Description structure
1. one-sentence episode promise
2. what the child will explore
3. short parent-facing learning note
4. optional playlist/series context
5. brand closing

### Hashtag structure
Use a small consistent set, for example:

`#Rere #BelajarBersamaRere #BelajarSambilBermain`

Add 2–4 topic-specific hashtags when useful. Do not turn hashtags into keyword stuffing.

## 8. Thumbnail system

Use the existing thumbnail/title packaging bible as the canonical production reference:

`docs/THUMBNAIL-TITLE-PACKAGING-BIBLE.md`

Thumbnail must:
- be understandable at small size
- feature Rere or the central learning object when appropriate
- communicate one clear idea
- avoid clutter
- preserve canonical Rere identity
- avoid misleading expressions or claims

## 9. Filename convention

Long-form:
`RERE-EP###-[SHORT-SLUG]-LONGFORM-V##`

Shorts:
`RERE-EP###-SH##-[SHORT-SLUG]-V##`

Final storage location and file format are governed by the production workflow.

## 10. Audience classification note

YouTube currently requires creators to identify whether content is Made for Kids. A channel-level setting can apply to existing and future videos, while individual video settings can override it. Because Rere is explicitly designed for children ages 2–4, this is a critical launch configuration rather than an afterthought.

Do not treat platform automation as a substitute for accurate creator classification.

## 12. Launch acceptance criteria

Channel setup is accepted only when:

- channel exists
- final name and handle recorded
- avatar uploaded
- banner uploaded
- description saved
- audience configuration recorded
- country/region and keywords configured
- home layout configured
- initial playlists created
- upload metadata template documented
- thumbnail system linked
- first-video publishing checklist linked
- channel URL recorded in the project control record
