# Rere — DISCOVER Curriculum Stress Test

**Status:** Passed with refinements — 2026-09-11

## Purpose

Stress-test the DISCOVER learning framework against a broad set of realistic early-childhood learning experiences before using it as a stable foundation for the wider 3-Year Curriculum Roadmap.

The test checks whether:

1. the activity has a natural DISCOVER interpretation when the learning intention is cognitive/world-understanding focused;
2. the six-stage progression remains useful beyond academic topics;
3. literacy and numeracy remain cross-domain rather than becoming hidden sub-pillars;
4. physical, social, emotional, and creative experiences can integrate without forcing DISCOVER to absorb them;
5. the framework exposes meaningful gaps or unnecessary strands.

This is a curriculum architecture test, not a developmental diagnostic.

## Evidence Guardrails

The stress test follows a play-based, developmentally appropriate orientation. NAEYC describes developmentally appropriate practice as strengths-based and play-based, and emphasizes that play can integrate cognitive, physical, social, emotional, language, and content learning. citeturn0search1turn0search12

CDC milestone materials are used only as broad developmental reference points, not as rigid curriculum gates. ## Results

### Quantitative Result

- 30/30 core stress-test experiences fit DISCOVER naturally when the primary learning intention is world understanding, exploration, relationships, or cognitive investigation.
- 12/12 boundary tests correctly distinguish DISCOVER from another primary pillar by learning intention.
- 0 red flags indicating a missing fundamental learning strand.

### What the Test Confirms

**1. The six-stage progression is coherent.**

NOTICE → CONNECT → WONDER → INVESTIGATE → REASON → APPLY can describe a genuine increase in cognitive participation without requiring a school-subject structure.

**2. DISCOVER is broad enough without becoming a catch-all.**

The framework covers recognition, relationships, mathematical thinking, literacy foundations, investigation, the natural/physical world, memory, attention, and curiosity.

**3. Cross-domain boundaries remain healthy.**

An activity does not automatically become DISCOVER. The learning intention determines the primary pillar.

**4. Literacy and numeracy remain appropriately cross-domain.**

They have substantial representation inside DISCOVER but can naturally move into SPEAK, FEEL, LIVE, or CREATE depending on the intention.

**5. Physical development does not need a separate DISCOVER strand.**

Movement can support exploration, but gross/fine motor development remains a cross-domain capability.

**6. Problem solving belongs naturally inside DISCOVER while remaining cross-domain.**

Problem solving is a capability/process, not a separate pillar.

## Refinements From the Stress Test

The stress test does not require a structural change to DISCOVER, but it produces four implementation rules:

### Refinement A — Do not turn every "why" question into DISCOVER

A child asking "why is Rere sad?" is primarily FEEL if the intention is emotional understanding. A child asking "why did the tower fall?" is DISCOVER if the intention is causal investigation.

### Refinement B — Use concrete experience before abstraction

Especially in the earlier phases, concepts should be experienced through objects, movement, visuals, routines, and play before expecting symbolic explanations.

### Refinement C — Revisit concepts with increased cognitive demand

The curriculum should spiral. The same concept can return with a different demand:

**Notice → Match → Compare → Predict → Investigate → Explain/Apply**

### Refinement D — Preserve child agency

When appropriate, guided play can provide a learning goal while allowing the child to make choices and direct parts of the experience. This aligns with NAEYC's description of playful learning as a spectrum that includes guided play rather than only free play or direct instruction. citeturn0search6turn0search12

## Final Verdict

**DISCOVER PASSES the current architecture stress test.**

No new strand or sixth pillar is required.

The framework is strong enough to become a stable component of the Rere 3-Year Learning Roadmap while remaining open to future refinement.
