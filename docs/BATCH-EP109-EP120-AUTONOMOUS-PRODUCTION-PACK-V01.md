### Integration rules
These episodes retrieve previously introduced concepts instead of adding large new concept sets. Keep one task active at a time. Reuse canonical learning objects and approved footage where continuity improves. EP117 must sequence match → count → sort visibly. EP118 must use only previously learned shapes/colors/patterns. EP119 is a retrieval sampler, not a new lesson. EP120 is a celebration and demonstration, not an assessment with pass/fail language.

### Safety/QA
Morning/night routines are calm and non-threatening. Preference episode validates either safe choice. Emotion episode validates different feelings and avoids trauma. All integration tasks have concrete visible answers/actions. No grading, scores, shame, comparison between children, or “smart/stupid” framing.

### Gemini contract
Attach only relevant canonical references. Prompt modules: SYSTEM → CHARACTER → WORLD → PROP → OBJECTIVE → ACTION → CAMERA → LIGHT → MOTION → SCENE → NEGATIVE → QA. For every generated shot verify identity, continuity, learning target, physical action, and absence of text artifacts. Reject P0/P1.
