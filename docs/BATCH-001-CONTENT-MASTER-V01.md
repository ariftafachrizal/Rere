# RERE — BATCH 001 CONTENT MASTER V01

**Batch:** BATCH-001  
**Episodes:** RERE-EP-001 → RERE-EP-006  
**Audience:** 2–4 years  
**Language:** Bahasa Indonesia  
**Status:** CONTENT MASTER — V01  
**Date:** 2026-09-12

## 1. Purpose

This is the single content-level source of truth for the first six-episode production batch. It prevents episode concepts from drifting apart and defines the learning progression before individual scripts are expanded.

Core philosophy:

**PLAY → EXPERIENCE → IMITATE → LEARN**

Core pillars:

**DISCOVER · SPEAK · FEEL · LIVE · CREATE**

## 2. Batch Learning Journey

| Episode | Working title | Primary pillar | Progression | Core child action |
|---|---|---|---|---|
| EP001 | Rere dan Petualangan Warna | DISCOVER | Recognize | point/name |
| EP002 | Rere dan Petualangan Bentuk | DISCOVER | Recognize → Match | point/match |
| EP003 | Rere Belajar Angka 1–5 | DISCOVER | Recognize → Count | count |
| EP004 | Rere Bermain Cocokkan | DISCOVER | Match | choose/match |

## 3. Batch-Level Rules

1. One episode has one primary learning promise.
2. All episodes use the canonical Rere opening and closing.
3. Rere remains a learning companion.
4. Repetition is intentional and contextual.
5. Every suitable episode includes child participation and PAUSE.
6. Difficulty increases gradually.
7. Do not introduce unnecessary new worlds or characters.
8. Reuse canonical assets aggressively where pedagogically appropriate.
9. New assets become derivatives only after approval.
10. No scene is approved solely because it looks attractive; learning clarity is mandatory.

## 4. Episode Objective Cards

### EP001 — Petualangan Warna

**Promise:** Anak mengenali dan mulai menyebut lima warna familiar.  
**Vocabulary:** merah, kuning, biru, hijau, pink.  
**Action:** menunjuk/menyebutkan.  
**World:** Playroom.  
**Story:** Rere ingin menggambar dan mencari warna yang ia perlukan.

### EP002 — Petualangan Bentuk

**Promise:** Anak mengenali bentuk lingkaran, persegi, dan segitiga pada benda familiar.  
**Vocabulary:** lingkaran, persegi, segitiga.  
**Action:** menunjuk/mencocokkan.  
**World:** Playroom.  
**Story:** Rere mencari bentuk untuk menyelesaikan gambar sederhana.

### EP003 — Angka 1–5

**Promise:** Anak mulai mengenali urutan angka 1–5 melalui benda konkret.  
**Vocabulary:** satu, dua, tiga, empat, lima.  
**Action:** menunjuk dan menghitung bersama.  
**World:** Playroom.  
**Story:** Rere mengumpulkan beberapa benda mainan untuk menghitung.

### EP004 — Bermain Cocokkan

**Promise:** Anak belajar menemukan dua benda yang sama berdasarkan satu ciri yang jelas.  
**Vocabulary:** sama, cocok, pasangan.  
**Action:** memilih/mencocokkan.  
**World:** Playroom.  
**Story:** Rere menemukan benda-benda yang kehilangan pasangannya.

### EP005 — Bagian Tubuh

**Promise:** Anak mengenali dan menyebut bagian tubuh dasar.  
**Vocabulary:** mata, hidung, mulut, tangan, kaki.  
**Action:** menunjuk/menyebut/meniru.  
**World:** Playroom.  
**Story:** Rere bermain permainan tubuh sederhana di depan cermin.

### EP006 — Merapikan Mainan

**Promise:** Anak memahami bahwa mainan dapat dikembalikan ke tempatnya setelah bermain.  
**Vocabulary:** main, rapikan, simpan, tempatnya.  
**Action:** mengambil, mengelompokkan, menyimpan.  
**World:** Playroom.  
**Story:** Waktu bermain selesai dan Rere mengajak teman-teman membuat playroom rapi.

## 5. Difficulty Guardrails

- EP001 focuses primarily on recognition.
- EP002 adds matching only after recognition.
- EP003 introduces sequential counting with concrete objects.
- EP004 focuses on matching without adding unnecessary attributes.
- EP005 moves vocabulary into body imitation.
- EP006 converts learning into a simple daily-life action.

Do not make later episodes harder merely for novelty.

## 6. Cross-Episode Recurring Structure

Each episode should normally contain:

1. Signature opening
2. Story hook
3. Optional short CTA
4. Discovery/activity
5. Participation cycles
6. Review
7. Achievement
8. Signature closing

The exact number of scenes can change, but the experience should remain recognizable as Rere.

## 7. Cross-Episode Recurring Assets

Priority reuse:

- Rere canonical character
- canonical regular outfit
- Playroom environment
- Pink Bunny
- Pink Backpack
- Learning Book
- Crayon Kit
- Learning Box
- selected location anchors

New assets are introduced only when they materially improve the learning objective.

## 8. Episode Dependency Map

EP001 establishes object/color vocabulary.  
EP002 reuses visual classification skills and introduces shape.  
EP003 introduces quantity/sequence.  
EP004 combines recognition and matching.  
EP005 shifts from objects to self/body vocabulary.  
EP006 applies sorting and routine concepts to daily life.

## 9. Cross-Episode QA

Before batch approval, verify:

- Rere looks identical across all episodes.
- Recurring props look identical across all episodes.
- Playroom geography does not drift.
- Opening and closing are recognizable.
- Difficulty progression is logical.
- No episode duplicates another without a deliberate learning reason.
- Vocabulary is age-appropriate.
- Visual palette remains coherent.
- Audio identity remains coherent.
- Packaging clearly distinguishes each episode.

## 10. Production Order

Content development should proceed in this order:

1. Lock this batch master.
2. Build shared learning-prop derivatives.
3. Build episode objective cards.
4. Write six scripts.
5. Storyboard six episodes.
6. Generate only required unique scene assets.
7. Record/generate voice in a consolidated session.
8. Produce audio using shared identity.
9. Edit from the shared template.
10. Run batch QA.
11. Package all episodes.
12. Publish according to release plan.
13. Feed performance learnings into Batch 002.
