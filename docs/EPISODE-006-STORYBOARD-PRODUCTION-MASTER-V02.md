## 0. PURPOSE

Episode ini mengajarkan rutinitas sederhana setelah bermain: **ambil → bawa → simpan di tempatnya**. Fokus pada action nyata, bukan sekadar before/after visual.

**Learning flow:** NOTICE MESS → CHOOSE ONE → PICK UP → CARRY → PUT AWAY → REPEAT → INVITE CHILD → RECAP.

**Core value:** tanggung jawab dan kemandirian sederhana setelah bermain.

---

# 1. CANONICAL LOCKS

- Canonical Rere character/face/anatomy/outfit.
- `RERE-WORLD-PLAYROOM-01`.
- Approved storage destinations from the world/prop system.
- Approved balls and blocks from the learning/prop asset set.
- Furniture and storage location remain fixed.
- No magical disappearance; every toy movement must be physically shown.

---

# 2. GLOBAL VISUAL RULES

- “Messy” means a manageable preschool play area, not a dangerous pile.
- Two categories only: balls → basket; blocks → box.
- One item/action at a time during teaching.
- Storage destination is visible before Rere moves the object.
- Rere carries objects safely, with realistic hand/body mechanics.
- Never place toys where they block walking paths or create hazards.
- Motion level 1–2; no frantic cleaning montage.

---

# 3. CONTINUITY MAP

The playroom begins with a small number of toys on the rug/floor. Canonical basket remains in its fixed location; canonical storage box remains in its fixed location. Rere first handles one ball, then one block. Items that are put away stay away. The room gradually becomes more organized without a magical reset.

### Action chain invariant
**SEE ITEM → PICK UP → CARRY → REACH DESTINATION → PLACE INSIDE → RELEASE → SHOW RESULT.**

# 5. EDITING / AUDIO RULES

- Physical action must be visible from pick-up through release.
- Avoid montage speed that hides the behavior being taught.
- Music ducks during instructions and pause.
- Use subtle pickup/place SFX as reinforcement.
- Keep storage geography consistent across all shots.
- If a clip contains impossible object disappearance, reject it instead of masking with an edit.

# 6. GEMINI PACKAGE

Attach: canonical Rere → face if needed → regular outfit → canonical playroom → approved ball/block/storage references → shot specification.

**Universal negative:** no character redesign, face drift, hairstyle/outfit drift, adult proportions, extra fingers/limbs/eyes, malformed hands/feet, floating toys, disappearing toys, teleporting objects, random props, world drift, storage relocation, photorealism, scary mood, text artifacts, watermark/logo, clutter, unsafe furniture, excessive camera motion.

# 7. QA GATE

- [ ] Pick-up → carry → place → release is visible.
- [ ] Destination is obvious before action.
- [ ] Toys never disappear magically.
- [ ] Storage locations remain fixed.
- [ ] Child can imitate safely.
- [ ] Canonical Rere/world/props remain stable.
- [ ] PAUSE is preserved.

**Golden rule:** teach the routine through real, visible action—not a magical before/after.
