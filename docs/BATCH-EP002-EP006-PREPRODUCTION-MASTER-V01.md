# RERE — PRE-PRODUCTION MASTER EP002–EP006 V01

**Status:** PRE-PRODUCTION READY — execution-ready after canonical reference attachment
**Purpose:** episode-specific production container equivalent to the EP001 production package.
**Canonical rule:** this document does not redesign or supersede locked Batch 001 storyboards; it operationalizes them for execution.

## Universal execution contract
- Audience 2–4; long-form 3–4 min; Shorts 20–40s (15–45s acceptable).
- Indonesian spoken master; exact canonical opening and closing.
- PLAY → EXPERIENCE → IMITATE → LEARN.
- Flow: S01 opening → S02 hook → S03 mission → S04–S06 teaching → S07 participation + PAUSE 3–5s → S08 review/reward → S09 closing.
- Attach references in order: canonical Rere → face/expression if needed → outfit → world → recurring prop → learning object → shot spec.
- Default Shorts: reuse approved long-form footage, crop/reframe 9:16, then QA. Dedicated vertical generation only if crop fails.
- Universal negative: no identity/face/hairstyle/outfit drift, adult proportions, extra/malformed anatomy, photorealism, scary imagery, random props, text artifacts, watermark, clutter, excessive bloom, overstimulation.
