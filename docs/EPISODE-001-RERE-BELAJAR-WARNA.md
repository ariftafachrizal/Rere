# Rere Episode 001 — Rere Belajar Warna

**Status:** Working Episode Brief — 2026-09-11
**Target:** 2–4 tahun
**Language:** Bahasa Indonesia
**Primary pillar:** DISCOVER / Recognition & Classification
**Primary objective:** mengenali dan mulai menyebutkan lima warna: merah, kuning, biru, hijau, pink.

## Episode Story

Rere sedang ingin menggambar. Saat melihat krayonnya, Rere penasaran dengan berbagai warna di sekelilingnya. Rere mengajak penonton melakukan “Petualangan Warna” dan menemukan warna melalui benda-benda yang familiar.

Story flow:

1. Rere ingin menggambar.
2. Rere menemukan bahwa banyak benda memiliki warna berbeda.
3. Rere mencari merah, kuning, biru, hijau, dan pink.
4. Rere mengajak anak mengulang setiap warna.
5. Rere melakukan mini quiz.
6. Rere menyelesaikan gambar dengan lima warna.
7. Signature closing.

## Standard Macro Structure

1. Signature Intro
2. Theme / Story Hook
3. Short CTA
4. Learning Story

Rere:

>

## Scene 3 — Short CTA

Keep it very short so it does not interrupt learning.

Suggested:

> “Kalau suka main dan belajar bersama Rere, jangan lupa subscribe ya!”
>
> “Sekarang... yuk kita mulai!”

A child-first alternative is a short visual subscribe overlay without extended spoken CTA.

## Visual Direction

Base environment: Rere playroom / study room.

Keep layout and Rere visual identity consistent with the character bible.

Visual style:

- polished 3D kawaii
- soft pastel
- warm light
- clean child-safe composition
- simple focal object per shot
- gentle camera movement

## Interaction Design

For each color:

**Find → Name object → Ask color → Pause → Reveal → Repeat → Reward**

## Audio Direction

- Rere voice remains clearly dominant.
- Gentle playful music.
- Reduce music during pause/question moments.
- Soft chime for correct answer.
- Avoid loud surprise effects.

## English Exposure — Optional Supporting Layer

Because the project direction includes natural English exposure, English should remain light and contextual.

Example:

> “Apel. Apple!”
>
> “Merah. Red!”

Do not turn this first episode into an English lesson. The primary objective remains Indonesian color recognition.
