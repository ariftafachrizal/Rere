# RERE — AUTONOMOUS EPISODE PRODUCTION SPEC V02

**Scope:** EP002–EP120, reusable for all episodes.
**Purpose:** eliminate routine ChatGPT dependency after an episode's curriculum row and canonical systems are locked.

## Source order
1. `docs/RERE-EPISODE-CURRICULUM-EP001-EP120-V01.md`
2. episode-specific pre-production container (dedicated episode file or canonical batch container)
3. canonical character / world / prop bibles
4. batch QA / voice / editing / packaging systems

Never reverse this hierarchy. A batch container is valid only when its episode row contains the complete seven-artifact contract: CONTENT LOCK, SCRIPT LOCK, STORYBOARD PRODUCTION MASTER, ASSET MAPPING GEMINI, SHOT PROMPTS, PRODUCTION HANDOFF, and SHORTS PRODUCTION PACK.

## Autonomous execution loop
`Todoist task → open canonical pre-production container → verify readiness → attach canonical references → Gemini generation/reuse → inspect → save → shot QA → episode QA → voice/audio → edit → package → publish → learning review`

## Content generation contract
Use the curriculum row as the single learning promise. Build a short 3–4 minute preschool experience with:
`HOOK → NOTICE/EXPERIENCE → QUESTION/INVITATION → PAUSE → ANSWER/ACTION → REPEAT → CREATE/TRANSFER → RECALL → CANONICAL CLOSING`
Keep spoken Indonesian simple and natural. Do not introduce a second primary objective.

## Visual generation contract
Attach minimum relevant canonical references in order: Rere → face/expression if needed → outfit → world/location → recurring prop(s) → learning object(s) → shot directive. Never redesign canonical assets.

## QA contract
Reject P0/P1 immediately. Verify intended concept is visually dominant, one plausible answer exists, PAUSE is stable, answer is not leaked before PAUSE, Rere gaze/gesture supports target, object count/geometry is exact where relevant, and actions are physically believable.

## Shorts contract
Five Shorts per episode by default. Reuse approved long-form footage first and crop/reframe 9:16. Dedicated vertical generation only if crop fails QA. Pattern: `HOOK → QUESTION/CHALLENGE → PAUSE → ANSWER/ACTION → REINFORCEMENT → MICRO-CLOSE`.

## Completion contract
A Todoist task may be marked complete only when the described artifact/action actually exists. PRE-PRODUCTION READY means the repository contains the complete executable planning contract; it does not mean visual/audio/editing deliverables exist. Production-complete requires actual deliverables and QA evidence.

## No-confirmation rule
Routine production decisions already established in canonical documents do not require owner confirmation. Escalate only when changing locked brand, learning, safety, canonical asset, storyboard baseline, or production system.
