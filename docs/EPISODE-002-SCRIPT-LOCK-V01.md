## Learning Goal
Anak mengenali tiga bentuk dasar: **lingkaran, persegi, segitiga**, lalu mencocokkan bentuk yang sama.

## Learning Progression
**SEE → TOUCH/POINT → NAME → MATCH → CREATE → RECALL**

No new shape is introduced after the first three learning targets.

## Canonical Interaction
Rere → question → **PAUSE 4 sec** → child response/action → reveal/reinforcement.
