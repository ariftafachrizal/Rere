- [ ] Learning promise is visible and singular.
- [ ] Child action is physically understandable.
- [ ] Question has enough visual information to answer.
- [ ] PAUSE is preserved and not visually interrupted.
- [ ] Rere points/looks at the intended learning object.
- [ ] Canonical character source is mandatory.
- [ ] Canonical world source is mandatory for recurring locations.
- [ ] Recurring props use canonical sources.
- [ ] Camera follows child-perspective rules.
- [ ] Lighting follows canonical world grade.
- [ ] No scene introduces a new visual language.
- [ ] No generation proceeds if source references are missing.
