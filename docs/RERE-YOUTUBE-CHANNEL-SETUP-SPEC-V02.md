## 3. PROFILE / AVATAR

- Use canonical Rere identity.
- Close-up face + slight shoulders.
- High fountain ponytail visible.

## 7. AUDIENCE — CRITICAL

**Recommended channel setting: “Yes, set this channel as made for kids. I mostly upload content that's made for kids.”**

Reason: Rere is intentionally designed as children's content for ages 2–4. This must be configured accurately in YouTube Studio.

Operational consequence: expect restrictions on comments, notifications, personalized advertising and other platform features for Made for Kids content. Do not design the business model around features that are unavailable to Made for Kids content.

Video-level audience settings still need to be checked during upload. If a future video materially differs in intended audience, evaluate that video separately.

## 8. CHANNEL VISIBILITY

**Public — LOCKED for launch.**

Do not publish unfinished content merely to make the channel appear active. Channel can be configured before first publication, but first public upload must pass the publishing gate.

## 10. PLAYLIST ARCHITECTURE

Create these initial playlists:

1. **Mulai Belajar Bersama Rere** — onboarding / best starting point.
2. **Belajar Konsep Dasar** — colors, shapes, numbers, matching, early concepts.
3. **Bahasa & Bicara** — vocabulary, sounds, descriptions, early literacy.
4. **Perasaan & Berteman** — emotions, sharing, turn-taking, social language.
5. **Kebiasaan Baik** — routines and practical daily-life habits.
6. **Kreasi & Imajinasi** — drawing, patterns, creative play and simple problem solving.
7. **Rere Shorts** — short-form learning interactions.

Do not create dozens of narrow playlists at launch.

## 11. UPLOAD DEFAULTS

Where YouTube allows reusable defaults, use the following as the baseline. Recheck each upload before publishing.

### Title formula
`Rere [Learning Topic] — [Activity/Adventure] | Belajar Bersama Rere`

Example:
`Rere Belajar Warna — Petualangan Warna | Belajar Bersama Rere`

### Description formula
1. One-sentence learning promise.
2. Short child-facing activity description.
3. Parent/caregiver learning note.
4. Relevant playlist/series context.
5. Brand closing.

### Hashtags
Base:
`#Rere #BelajarBersamaRere #BelajarSambilBermain`

Add 1–3 relevant topic hashtags only when useful.

Avoid keyword stuffing, repetitive blocks, competitor names, or misleading tags.

## 12. THUMBNAIL SYSTEM

Canonical formula:
**RERE + ONE OBJECT + ONE LEARNING CUE**

Examples:
- EP001: Rere + apple + `WARNA APA?`
- EP003: Rere + counted objects + `AYO HITUNG!`
- EP005: Rere + eye + `MATA!`
- EP006: Rere + bunny + box + `AYO RAPIKAN!`

Rules:
- One clear idea.
- Large readable visual hierarchy.
- Minimal text.
- Canonical Rere identity.
- No misleading facial expressions.
- No visual clutter.
- Do not copy competitor thumbnail conventions.

## 14. VIDEO UPLOAD BASELINE

For the first production batch:
- Long-form: 16:9, approximately 3–4 minutes.
- Shorts: 9:16, preferred 20–40 seconds, acceptable 15–45 seconds.
- Spoken language: Indonesian.
- Audience: Made for Kids as appropriate to the channel/content classification.
- Title, description, thumbnail, playlist and audience setting must be checked before publish.

## 15. COMMENTS / COMMUNITY EXPECTATIONS

Do not attempt to build the launch strategy around comments or community posts. Made for Kids settings restrict these features.

Use learning design, repeat viewing, playlists, clear packaging, parent trust and content quality as the primary engagement system.

## 16. CHANNEL LINKS

At launch, keep links minimal and trustworthy.

Recommended priority:
1. Official Rere brand destination if one exists.
2. Other official Rere-owned social presence only when actually established.
3. Business/contact destination only when operationally ready.

Never add placeholder URLs.

## 17. ADVANCED SETTINGS / GOVERNANCE

- Audience: Made for Kids — see Section 7.
- Country: Indonesia.
- Channel visibility: Public for launch.
- Do not enable or configure features that conflict with the Made for Kids state.
- Do not use misleading metadata.

## 18. PUBLISHING GATE

A video may be published only after:

`PRODUCTION COMPLETE → FINAL QA → METADATA READY → THUMBNAIL READY → PLAYLIST SELECTED → UPLOAD → AUDIENCE CHECK → SETTINGS CHECK → PREVIEW → PUBLISH/SCHEDULE → RECORD PUBLICATION`

## 19. POST-PUBLISH RECORD

For every published video, record:
- final title
- public URL
- publish date/time
- playlist
- audience setting
- thumbnail version
- production version
- GitHub source references
- initial analytics baseline

## 20. ANALYTICS BASELINE

After sufficient data exists, review:
- impressions
- click-through rate where available
- views
- average view duration
- audience retention
- traffic sources
- returning/new viewers where available
- performance by long-form vs Shorts
- playlist performance where available

For Made for Kids content, expect some analytics/features to differ because YouTube restricts data collection and platform features.
