# RERE — AUTONOMOUS PRODUCTION PACK EP007–EP036 V01

Status: production baseline. Audience 2–4. Long-form 3–4 min; Shorts 20–40s.

## Universal production contract
Use locked canonical Rere, world, props, camera, lighting and voice. Never redesign canonical assets. Indonesian spoken master V01. Structure: S01 exact opening; S02 hook/discovery; S03 brief mission; S04–S06 concrete teaching one concept at a time; S07 question/instruction + PAUSE 3–5s; S08 review/reward; S09 exact closing. Apply PLAY → EXPERIENCE → IMITATE → LEARN. Generate Shorts by reusing approved long-form footage and 9:16 crop/reframe first. Dedicated vertical generation only if crop fails QA.

Universal negative: no identity drift, face/hairstyle/outfit drift, adult proportions, extra/malformed anatomy, scary imagery, photorealism, random props, text artifacts, watermark, clutter, excessive bloom, overstimulation.

## Safety/QA locks
EP010: sets clearly separated and countable. EP012: one AB pattern only. EP017: child-safe washable setup, no ingestion. EP021–022: friendly non-startling animals. EP025: no dangerous storms. EP027: no germs/disgust closeups. EP028–029: simple realistic routines, no medical claims. EP030: no dieting/calorie/weight language. EP031–032: respectful voluntary sharing/turn-taking, no forced contact. EP035–036: validate feelings; no shame, diagnosis, forced breath-holding or clinical claims.

Acceptance: P0/P1 reject. One plausible answer per question; physical actions coherent; identity/world/props stable; learning understandable without on-screen text. Routine production requires no owner confirmation; escalate only if changing locked brand, learning, safety, canonical assets, storyboard baseline or production system.
