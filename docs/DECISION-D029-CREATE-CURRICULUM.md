# Decision D-029 — CREATE Curriculum

**Date:** 2026-09-12  
**Status:** Approved  
**Decision:** CREATE is finalized as the fifth Core Pillar of the Rere learning architecture.

## Context

CREATE was previously approved as a Core candidate. Its framework now has a three-year developmental progression, a three-year curriculum roadmap, and a 40-case stress test.

## Final Identity

> **CREATE — Imagine, Express & Make**

Purpose:

> CREATE membantu anak membayangkan, mengekspresikan, mencoba, dan menciptakan sesuatu dengan caranya sendiri.

Core progression:

**EXPLORE → IMITATE → VARY → CREATE → SHARE & EXTEND**

Creative loop:

**IMAGINE → CREATE → SHARE**

Engagement ladder:

**WATCH → COPY → CHOOSE → CREATE → SHARE**

## Final Core Areas

1. **Creative Expression**
2. **Pretend Play & Imagination**
3. **Storytelling & Narrative Creation**
4. **Music, Rhythm & Movement**

Supporting/cross-cutting area:

5. **Open-Ended Making & Exploration**

## Core Principles

- Process over Product
- Participation over Perfection
- Exploration over Correctness
- Agency over Imitation
- Expression over Performance

A Rere example is an invitation, not a template that must be copied.

## Primary Intention Rule

CREATE is selected when the primary learning intention is for the child to imagine, express, invent, transform, make, or create.

The same activity may belong to another pillar when the primary intention changes.

Examples:
- story creation → CREATE; language practice in a story → SPEAK;
- free-form building → CREATE; investigating why a bridge falls → DISCOVER;
- emotional role-play → CREATE + FEEL; learning emotion recognition/regulation → FEEL;
- pretend safety practice → CREATE + LIVE; learning actual safety behavior → LIVE.

## Three-Year Curriculum Direction

### Year 1 — Explore & Express

**EXPLORE → IMITATE → VARY**

Build comfort with marks, sounds, movement, symbolic play, simple stories, and open choices.

### Year 2 — Choose & Create

**VARY → CREATE**

Increase child choice, combinations, imaginative scenarios, original story elements, simple rhythms, movement creation, and open-ended making.

### Year 3 — Create, Share & Extend

**CREATE → SHARE & EXTEND**

Increase sustained ideas, transformation, narrative development, collaborative pretend play, shared music/movement, and creative adaptation.

Age remains a developmental reference, not a gate.

## Stress-Test Result

The CREATE roadmap was tested against 40 cases covering creative expression, pretend play, storytelling, music, rhythm, movement, open-ended making, and boundary cases with the other pillars.

**Verdict: PASS — no structural change required.**

The strongest identified risk is not missing curriculum coverage but **adult-controlled product production**. This is addressed through the agency and process-over-product guardrails.

## What CREATE Must Not Become

CREATE must not become:

- a craft tutorial channel where the child only copies;
- an art-quality assessment;
- a performance test;
- a worksheet disguised as creativity;
- an adult-directed activity with no meaningful choice;
- a requirement to explain creativity verbally;
- a place where different cultural/family expressions are treated as incorrect.

## Relationship to Five-Pillar Architecture

With CREATE finalized, the Rere Core Pillars are complete:

1. **DISCOVER — Understand the World**
2. **SPEAK — Communicate with the World**
3. **FEEL — Understand Myself & Others**
4. **LIVE — Care for Myself, Others & My World**
5. **CREATE — Imagine, Express & Make**

They remain learning lenses rather than five isolated school subjects.

The governing architecture remains:

> **Clear primary learning + rich natural integration.**

And:

> **Activity does not determine the pillar. Learning intention determines the pillar.**

## Consequence

No additional Core Pillar should be added based on the current architecture.

The next major curriculum task is integration: build the complete **Rere Three-Year Learning Architecture + Episode System** across all five pillars, including common episode metadata, learning-intention selection, developmental complexity, cross-domain capabilities, quality gates, and production handoff to Gemini.
