# RERE — BRAND NAME DECISION V02

**Date:** 2026-09-14
**Status:** DECIDED / SUPERSEDES V01

## Decision

Public channel/series brand changes from **Rere dan Kelinci Pink** to **Rere dan Cipi**.

The character **Rere** remains unchanged. The existing canonical Pink Bunny asset remains the visual source of truth for the companion. The bunny's public character name is now **Cipi**, with the descriptor **Cipi — Kelinci Pintar**.

## Brand Architecture

- **Public Brand:** Rere dan Cipi
- **Main Character:** Rere
- **Companion Character:** Cipi
- **Descriptor:** Cipi — Kelinci Pintar
- **Visual descriptor:** Cipi is the pink bunny companion
- **Core signature:** BELAJAR • BERMAIN • BERBAGI
- **Supporting phrase:** MAIN • COBA • TEMUKAN

## Why

Cipi converts the previously generic companion descriptor “Kelinci Pink” into a memorable proper character name. This makes the duo easier for children and parents to remember, easier to use in dialogue, and stronger as a long-term character/IP architecture.

The name “Rere dan Cipi” also preserves the existing Rere investment while creating a shorter, more distinctive public-facing duo name.

## What changes

- Public channel/series name: **Rere dan Cipi**
- Target YouTube handle: **@RereDanCipi** (must be verified live)
- Companion name: **Cipi**
- Companion descriptor: **Kelinci Pintar**
- Banner, profile, watermark and other public brand assets should use the Rere + Cipi duo.
- Opening and closing should introduce and reinforce Cipi.
- Public copy should prefer “Cipi” over “Kelinci Pink” when referring to the character.

## What does not change

- Rere character identity, personality, face, anatomy, hairstyle, outfit system and canonical references.
- Existing canonical bunny visual design. Naming the bunny does not authorize a visual redesign.
- Curriculum, episode numbering, learning pillars, production pipeline and QA system.
- **BELAJAR • BERMAIN • BERBAGI** remains the core brand signature.

## Character Role

Cipi is not a second teacher. Cipi is Rere's curious companion who can ask, react, guess, make safe mistakes, try again and learn alongside the audience.

“Pintar” means curious, willing to try and willing to learn — not always knowing the answer.

## Signature Opening — Recommended Lock

> **“Hai teman-teman! Aku Rere, dan ini Cipi! Yuk main dan belajar bersama kami!”**

Target: approximately 8–10 seconds.

## Signature Closing — Recommended Lock

> “Hebat sekali hari ini!”
> “Terima kasih sudah belajar bersama Rere dan Cipi!”
> “Belajar... Bermain... Berbagi... Bersama Rere dan Cipi!”
> “Sampai jumpa, teman-teman! Dadah!”

## Verification Gate

Before changing the live public channel identity, verify the new brand/handle directly in:

- YouTube Studio handle registry
- Instagram
- TikTok
- DJKI

The previous clearance of “Rere dan Kelinci Pink” does **not** automatically clear “Rere dan Cipi”.

## Migration Rule

Do not treat the old “Rere Yuk Main!” or “Rere dan Kelinci Pink” wording as canonical after the new brand is verified and applied. Historical documents may retain old wording only when describing the previous decision/state.
