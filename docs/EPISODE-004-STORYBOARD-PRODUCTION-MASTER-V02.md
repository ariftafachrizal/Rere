## 0. PURPOSE

Episode ini mengajarkan konsep **pasangan yang sama** melalui visual matching. Fokus bukan pada menghafal nama benda, tetapi membandingkan satu benda dengan kandidat pasangannya.

**Learning flow:** SEE → COMPARE → QUESTION → PAUSE → MATCH → REWARD → REPEAT.

**Critical rule:** setiap task matching memiliki **satu jawaban yang jelas**.

---

# 1. CANONICAL LOCKS

- Canonical Rere character/face/anatomy/outfit.
- `RERE-WORLD-PLAYROOM-01`.
- Approved matching assets: three stable object pairs.
- Same object within a pair must have identical silhouette, scale, color and visible details.
- Camera child-height; learning plane uncluttered.
- No shot-level redesign of character, world or approved props.

---

# 2. MATCHING DESIGN RULES

1. One criterion at a time: **same object/visual identity**.
2. Never place two equally plausible candidates.
3. Candidate positions must be clearly separated.
4. Matched objects remain visible after pairing.
5. Rere must visually compare before moving the answer.
6. During pause, Rere must not reveal the answer through a premature movement.
7. No hidden distractors.

---

# 3. CONTINUITY MAP

Rere works at the same playroom learning table. Three “source” objects are placed on the left and their three partners are placed on the right in a deliberately mixed order. One pair is solved at a time. After each correct match, the pair remains together in a stable completed area.

Suggested stable pairs from approved matching set:
- Pair A: identical ball objects.
- Pair B: identical block objects.
- Pair C: identical shape-card objects.

Use the actual approved assets from the repository rather than regenerating a new visual family.

# 5. EDITING / AUDIO RULES

- Never cut away from the candidate set during the question/pause.
- Pause 4–5 sec; music ducks.
- Match action should be shown in real time, not implied by a jump cut.
- Use a subtle placement/reward sound after the correct pair.
- Preserve completed pairs across transitions.

# 6. GEMINI PACKAGE

Attach: canonical Rere → face if needed → outfit → canonical playroom → exact approved pair assets → shot spec.

**Universal negative:** no character redesign, face drift, hairstyle/outfit drift, adult proportions, extra fingers/limbs/eyes, malformed hands, extra objects, duplicate candidates, ambiguous matches, floating objects, geometry drift, text artifacts, watermark/logo, photorealism, scary mood, clutter, excessive motion.

# 7. QA GATE

- [ ] Each task has exactly one correct partner.
- [ ] Pair members are visually identical.
- [ ] No answer is leaked during PAUSE.
- [ ] Completed pairs remain stable.
- [ ] Child can compare visually without obstruction.
- [ ] Canonical Rere/world/assets remain unchanged.

**Golden rule:** if there are two possible answers, the shot fails.
